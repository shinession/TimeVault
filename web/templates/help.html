What TimeVault is

TimeVault backs up selected folders on a server and keeps their history. Each backup adds a recovery point, a saved picture of the folder at one moment. You can look at a folder as it is now, go back to how it was earlier, find a file that was changed or deleted by mistake, and restore it. The pages Explorer, Time Machine and Backups are open to everyone; Audit, Settings and Status are for signed-in accounts.

What it does not do

  • It only reads the monitored folders; it never changes, moves or deletes anything in them.
  • A restore never overwrites the original files: it writes copies into a new folder inside the restore folder, and you copy back what you need.
  • It does not offer file contents for download; you pick restored copies up from the restore folder.
  • It reads the live disk, not snapshots, so every recovery point is labelled Live scan. A file locked by another program, or changing while it is read, can be skipped and shows as Not captured.

Common tasks

  • Get back a deleted file: in the Explorer open Deleted since the last backup, open the file and press Restore….
  • Get back an older version: click the file, then press Restore… beside the version (File versions).
  • Restore a whole folder: open it in the Time Machine and press Restore this folder….
  • Back up a folder now: press Back up now on Backups.
  • Change a schedule: press Edit in Settings.

Signing in and permissions

Without signing in

Anyone can browse. A visitor who has not signed in (a guest) can use the Explorer, the Time Machine, the file versions and the Backups page, but only for folders that allow guests; other folders are simply not there. Guests cannot back up or restore, cannot open Audit, Settings or Status, and do not see who started a job, why it failed or its log.

Signing in

  1. Press Sign in at the top right, or a button such as Sign in to back up.
  2. Enter your Account (employee ID, name or e-mail) and Password, then press Sign in. The employee ID is the least ambiguous.
  3. Or press Sign in with Windows (SSO) when it is offered: a small window opens and closes by itself (allow pop-ups for this site, and use your company computer).

You return to the page you came from. Signing in lasts a limited time (Settings, card Service, Sign-in lasts); press Sign out at the top right when you are done.

Access levels

What you may do is decided for each monitored folder, and each level includes the ones before it. Buttons you may not use are not shown.

LevelWhat it allows
BrowseSee the folder, its files and its history, and restore copies from it (restoring needs a signed-in account).
Back upEverything in Browse, and back up now (also a full re-read), verify recovery points and stop its jobs.
Full controlEverything in Back up, and change this folder's settings and who may do what with it.

A level can be given to guests (Browse only), to everyone who is signed in, or to named people; you get the highest one that applies. A folder on which you have no level is not visible to you. A chip next to a folder's name on Backups and Settings shows your level.

Administrators have Full control of every folder. Only they can add monitored folders, change a Folder on the server, see folders on the server's own disk and use Check now for program updates.

Explorer

The Explorer shows a monitored folder as it is on the disk right now and tells you, item by item, whether it is backed up.

The top of the page

  • The drop-down list chooses the monitored folder (only folders you may browse). The path bar shows the folders you opened; click a name to go back.
  • Location is the network path (display folder) of what you are looking at; Copy copies it (the button says Copied for a moment). Administrators also see On the server, with the real folder.
  • Last recovery point tells when the newest recovery point was made, with its integrity label (see Time Machine); Open in Time Machine shows the same folder there. A folder never backed up says This folder has not been backed up yet.

The file list

Click a folder to open it, or a file to see its versions. The columns are Name; Type (the extension in capitals, such as PDF; Folder; Link; File for a file without an extension); Backup; Size (a folder has one only when the search index knows it, otherwise “-”); and Modified. Backup shows:

Sorting, filtering and paging

  • Click Name, Type, Size or Modified to sort the whole folder, and again to reverse it. Folders come first.
  • The Type list keeps one kind of item: All types, or Folders, Files, No extension or one extension, each with the number of items it holds.
  • Per page sets 50, 100 (the default), 200 or 500 items; use Previous, Next and the page numbers. Your choices stay in the address, so a link opens the same view.

Search

  1. Type words from the name in the search box (press / to jump there) and press Search. A result must match all the words; use double quotes for a phrase; up to 16 words.
  2. Matches are listed with Name, Type, Folder, Size and Modified (100 per page; 50 or 200 can be chosen). Click a folder to open it, a file to see its versions. Clear search returns to the folder list.

The search covers the whole monitored folder, not only the open folder, and finds what is on the disk now, not deleted files. If the search index is off or not ready yet you see Search is unavailable right now (the search index is off, or not ready yet). Browsing and history still work.

Deleted since the last backup

On the first page, a panel lists up to 500 items that are in the newest recovery point but gone from the disk. Open a file and press Restore…; open a folder to see it in the Time Machine and press Restore this folder… (see Restoring files).

Time Machine

The Time Machine shows a monitored folder as it was at a recovery point you choose. Pick the folder in the list at the top. A folder without recovery points says No recovery points yet: run the first backup on Backups.

Click a dot to see the folder as it was then. A point that cannot be restored has a warning colour. The last dot, Now (Live files), leads back to the Explorer.

Restoring from here

Signed-in accounts see a tick box in front of each item and, above the list:

  • Restore selected…, with a counter, restores the ticked items; it stays disabled until you tick one. Select all selects only the items on the current page.
  • Restore this folder… (inside a folder) or Restore everything… (at the top of the monitored folder) restores the folder you are looking at and ignores ticks.

Visitors who are not signed in see Sign in to restore files and no tick boxes. Without a restore folder you see Restore is disabled because no restore folder is configured., and a Not restorable recovery point offers no restore buttons. Next: Restoring files.

File versions

Click a file (in the Explorer, the Time Machine, a search result or the deleted-items panel) to open its versions page: a Location line and a table of every recorded state of the file, newest first. Back returns to where you came from.

  • Captured and Until give the times of the first and the last recovery point that contain this version; Current under Until marks the newest state of the file.
  • Size and Modified are the file's size and modified date in this version. SHA-256 is the start of the content checksum (point at it for the whole value); equal checksums mean equal content.
  • Content says whether the stored copy can be used:
LabelMeaning
AvailableThe stored copy is there and can be restored.
Content missingThe stored copy is missing from the backup storage, so this version cannot be restored. Tell an administrator; another version may still work.
Not capturedThe backup could not read the file then (point at the label for the reason). Nothing to restore.
FolderThe entry is a folder.

At the end of each row, Restore… restores that version (signed-in accounts, when a restore folder is set up and the version was captured), and Browse point opens the Time Machine at the first recovery point that contains it, in the file's folder.

Restoring files

A restore copies files or folders from a recovery point into the restore folder. It never writes into a monitored folder and never overwrites the original files. You must be signed in and have at least the Browse level.

  1. Choose what to restore. In the Time Machine tick items and press Restore selected…, or press Restore this folder… or Restore everything…. On a file's versions page press Restore… beside the version you want. You can select up to 500 items at a time; a folder counts as one.
  2. Read the preview. The page Restore preview says Nothing has been written yet. It shows your selection, the Destination, a Summary (Files, Folders, Data, Create, Replace, Restore as copy, Skipped, Blocked), warnings, the Problems (blocked items and why; the first 100) and the Planned changes (the first 200 items). Each planned change is labelled Create folder, Folder exists, Create, Replace, Restore as copy, Already identical, Keep existing or Blocked (see the Glossary).
  3. Set the options if the defaults do not suit you (table below), then press Update preview. Changes count only after you press it.
  4. Confirm. Press Start restore within 15 minutes. If files would be replaced, first tick I understand that N existing file(s) will be replaced. The button is disabled while blocked items prevent the restore.
  5. Follow the job on its page (see Jobs). When it says Succeeded, the copies are in the destination folder.
  6. Collect your files. The Destination is a network path such as \\server\share\restore\restore-20261118-141257. Open it and copy what you need back. Each selected item is restored under its own name directly inside it (a whole monitored folder under that folder's name). If you see [restore folder]\restore-20261118-141257 instead, ask an administrator how to reach the restore folder.
OptionWhat it does
Destination folder nameThe folder inside the restore folder that receives the copies. Proposed as restore-<date>-<time>; created if it does not exist. Use letters, digits, spaces and . _ -.
If a file already existsKeep the existing file (skip) (the default) leaves a file that is already there alone. Keep both (restore under a new name) saves the copy next to it, named like report (restored 20261118-141300).docx. Replace the existing file replaces the file in the destination folder, never the original, and needs an extra confirmation.
Restore what is possible even if some items are blockedWithout the tick, one blocked item stops the whole restore. With it, everything else is restored and the blocked items are reported as failed.

Note: A preview is valid for 15 minutes, for you only and for exactly this selection and these options. Otherwise you see The preview is out of date. Review the new preview and confirm again. Restored files get the modified date and attributes of the recorded version. Do not start a second restore into the same destination folder while one is running.

Backups

The Backups page shows how the backups of each monitored folder you may browse are doing, lets people with the right level start them, and lists the recent jobs. If there is no folder to show, sign in or ask an administrator for access; administrators are offered Manage monitored folders.

A folder card

  • The heading shows the folder's name, Switched off if it is, and (when signed in) your level. Under it is the display folder; administrators also see On the server.
  • Back up now reads the folder, copies new and changed files into the backup storage and records a new recovery point; it never changes the folder. Full re-read does the same but reads every file again instead of trusting size and modified date; it is slower and also writes missing content again. Both need the Back up level and a folder that is switched on, and are greyed out while a backup of the folder is queued or running. A guest who could get them by signing in sees Sign in to back up.
  • While a backup runs the card shows Backup job #12 is in progress with its state, phase and a progress bar; click the number to open the job.
  • The facts: Latest recovery point (when, and its number; or Never), Schedule (for example every 60 min with the next backup, or Manual only), Last run (when the last run ended; an automatic run that found nothing changed counts, so it can be later than the latest recovery point) and Excluded (the patterns that are never backed up).

Recovery points

The table in each card lists the folder's 12 most recent backup attempts:

  • # is the number; Type is Full for the first recovery point of a folder and Incremental for later ones (each shows the whole folder); Captured is when it was made; Files and Size are what the folder held then.
  • State: Committed is finished and usable; Building is still being made; Failed and Aborted did not finish and show nothing (signed-in accounts can point at Failed for the reason).
  • Changes: +3 ~2 -1 files added, modified and deleted since the previous recovery point. Not captured counts the items the backup could not read (2 when above 0). Integrity shows the integrity label and Partial when it applies.
  • Browse opens the recovery point in the Time Machine. Verify (Back up level) re-reads every stored object and checks its checksum; the label becomes Verified or Failed. Use it after the backup storage was copied or restored, or whenever you want proof that a recovery point is intact.

Recent jobs and the Restore card

Recent jobs lists the 25 newest jobs of the folders you may browse (number, Type, Monitored folder, State, Created, Duration, Requested by); click the number to open the job. Only signed-in accounts see who requested a job, and only they see restores and the card Restore, which says where restores are written (Restores are written below a network folder) or that restore is disabled.

Jobs

Everything TimeVault does in the background is a job with a number: Backup, Verification, Restore or Version cleanup. A job is Queued while it waits its turn (the jobs of one folder take turns), then Running, and ends as Succeeded, Failed or Canceled. Open a job from the Backups page or from the page that started it.

  • Cancel job stops a job that is queued or running. It is offered to people with the Back up level on the folder, and to whoever started a restore.
  • The facts are Monitored folder, Recovery point, Requested by (signed-in accounts only; automatic backups are requested by scheduler), Created, Duration and Phase, which says what the job is doing now (for example Scanning and copying, Verifying, Restoring).
  • A progress bar and counters show the work done, and the page refreshes itself every second or two.
  • Error gives the reason for a failure; guests see It failed. Sign in to see the reason and the log. The card Log is for signed-in accounts.
  • The page of a restore job (signed-in accounts only) also has Restore details and a table Items with Name, Action, Result (OK, Skipped or Failed), Size and Message. The tabs All and Failed only filter it, and Load more shows the next 200. Every failed item is listed; on a very large restore the list of the other items stops after 20,000.

Note: A restore job ends as Failed when any item could not be restored, even if everything else was copied. That includes blocked items you left out with the partial restore option. Open Failed only to see which items and why.

Note: An automatic backup that finds nothing changed leaves no job behind, so a job you saw running may no longer exist when it ends.

Automatic backups and versions kept

Automatic backups

  • A folder can be backed up every N minutes (1 to 43200); someone with Full control sets it in Settings. The interval counts from the end of the previous backup. Backups and Settings show the schedule and the next backup (or any moment now); Manual only means no schedule. Folders that are due together are spread out, so a backup can start a little later than shown.
  • An automatic backup that finds nothing changed records nothing: no recovery point, no job, no audit entry. Last run still moves forward, while Latest recovery point stays. Back up now always records a recovery point.
  • A switched-off folder is not backed up. When you set a schedule, or switch a folder on, a backup starts at once if the last run is older than the interval.

Versions kept per file

  • Each folder can limit how many versions of a file are kept (1 to 10000; 0 keeps all). Settings shows Versions kept as All versions of every file or The newest N of each file.
  • After each backup, the files it changed lose the versions beyond the limit, for good, and storage that nothing uses any more is freed (this can take a while to show). A recovery point that lost versions is marked Partial: it no longer shows every file as it was, so a restore from it can be incomplete.
  • Setting the limit on a folder that has history, or lowering it, starts a Version cleanup job for the whole folder. The form first shows how many versions of how many files would go and asks you to tick I understand that these versions are deleted for good. While a cleanup runs, restores and verifications of that folder are refused and the limit cannot be changed.

Warning: Deleted versions cannot be brought back. Without a limit, a short interval on a folder that keeps changing makes the backup storage grow without bound.

Adding a folder (administrators)

Press Add a folder, fill in the same fields and press Add monitored folder. The Folder on the server must be a local folder that does not overlap the backup storage, the restore folder or another monitored folder; it is only ever read. The exclude patterns start as $RECYCLE.BIN, System Volume Information, Thumbs.db and ~$*. A new folder is seen by administrators only until you give somebody access to it.

Storage, service and updates

  • Backup storage shows where backups are kept (administrators see Backup folder (repository) with the real folder), its state and free space, and the Restore folder (where restored copies go) as a network folder, or not configured. Both are set in the service settings (TIMEVAULT_REPOSITORY_PATH and TIMEVAULT_RESTORE_ROOT in the .env file) and change only when the service is restarted.
  • Service shows the Version. The button Status opens the Status page. How the service is set up is not shown here: that is for the Site settings, a page that only the local administrator can open (the button Site settings appears here for that account). It has the settings that are kept in the database (the name of the server in network paths, sign-in, workers, the scheduler, the search index, updates and logging), each with its explanation and its default; a change takes effect after the service restarts, and the page then offers Restart now (it refuses while jobs run). At the bottom it lists what the environment and the .env file hold (the database, the listen address, the backup and restore folders, the user accounts in Redis, the local administrator). Secrets are never shown.
  • Program updates says whether TimeVault updates itself: when a different version is released, the service downloads and checks it, waits for the running jobs to finish and restarts itself; jobs requested meanwhile wait in the queue. The status is Up to date, Checking, Downloading, Waiting for the running jobs, Installing or Problem. Administrators also see the release address and the last problem, and can press Check now.

Status

The page Service status (signed-in accounts only; open it with Status in the footer or in the Settings card Service) says when it was checked and lists each Component with its State and a Detail. The states are OK, Degraded (working, with a problem), Not enabled (not set up) and Failed.

  • Database: OK, or Failed when it does not answer.
  • Repository (the backup storage): a write test and the free space. Degraded below 5% free, Failed when it cannot be written to.
  • Search index (NTFS): the index of the monitored folders that gives the Explorer its search and its folder sizes. OK when every volume is indexed (or there is nothing to index), Degraded while a volume is being built or when it cannot be indexed (the Detail says why: for example that the service needs administrator rights to read the volumes, or that a volume has no change journal), Not enabled when it is switched off.
  • User accounts (Redis): Degraded when it does not answer; browsing and the local administrator still work, but other accounts cannot sign in. Not enabled when it is not configured: only the local administrator can sign in.
  • Restore: OK, or Not enabled without a restore folder. Job queue: how many jobs are running and queued in the folders you may browse.
  • VSS snapshots is always Not enabled: TimeVault reads the live disk.

Problems and answers

I cannot see a monitored folder (“The page, folder or recovery point was not found, or you are not allowed to see it.”)

A folder is visible only to the people it was given to. Sign in if you have not; otherwise ask an administrator, or someone with Full control of the folder, to give you access (Settings, Edit, Who may do what).

“You are not allowed to do this.”

You can see the folder, but your level is too low: Back up is needed to back up, verify or stop a job, Full control to change settings, and only administrators add folders. The attempt is recorded in the audit log as Access denied.

The restore buttons are missing or disabled

You are not signed in (Sign in to restore files); or no restore folder is set up (Restore is disabled because no restore folder is configured.), which an administrator must fix; or you have ticked nothing (Restore selected… stays disabled); or the recovery point is Not restorable, so choose another one.

Signing in fails

Invalid account or password. Check what you typed; the employee ID is the safest account name. Too many failed attempts. Wait a few minutes and try again. Wait about ten minutes, even if the last password was right. The user accounts cannot be reached. Try again later; browsing still works.

Sign in with Windows (SSO) does not work

If the browser blocked the sign-in window, allow pop-ups for this site and try again. If Windows could not tell who you are, or has no active account for you here, open TimeVault from your company computer or use your password. Otherwise try again in the same browser on the same computer.

Search says it is unavailable

The search index is off, is still being built (a big volume takes a while after the service starts), or cannot read the volume. Everything else keeps working; try again later and tell an administrator if it continues: the Status page says why.

A job page says “not found”, or the job has disappeared

An automatic backup that finds nothing changed leaves no job. A job of a folder you may not browse is also “not found” for you.

Back up now is missing, or the folder shows “Switched off”

A switched-off folder cannot be backed up, but its history stays browsable. An administrator, or someone with Full control, switches it on in Settings (Back up this folder). You also need the Back up level.

“The form has expired or is invalid. Reload the page and try again.”

The page or your sign-in is too old. Reload the page (F5), sign in again if asked, and repeat the action.

“The preview is out of date…”, “A backup of this monitored folder is running” or “Old versions of this monitored folder are being deleted”

A restore preview expires after 15 minutes or when something changes (such as the files in the destination folder): check the new preview and press Start restore again. The jobs of one folder take turns, so for the other two messages wait until the running job has finished and try again.

A file shows “Not captured”, or stays “New”

Not captured: the backup could not read the file (for example another program had locked it, or it changed while being read). Point at the label for the reason and run the backup again later; such a file cannot be restored from that recovery point. New becomes Protected after the next successful backup; if it stays New, check Excluded on the Backups page, because files that match an exclude pattern are never backed up.

“The folder cannot be read right now. Time Machine history is still available.” or “Something went wrong on the server.”

The first means the monitored folder cannot be reached at the moment; history and restores keep working. For the second, note the Reference code. In both cases tell an administrator if it continues.

TimeVault 是什么

TimeVault 会备份服务器上选定的文件夹，并保留它们的历史。每次备份都会增加一个恢复点：文件夹在某一时刻的保存状态。你可以查看文件夹现在的样子，回到它较早时的样子，找出被误改或误删的文件，并把它恢复出来。页面文件浏览、时间机器和备份对所有人开放；审计、设置和状态只对已登录的账号开放。

它不会做什么

  • 它只读取监控文件夹，绝不会修改、移动或删除其中的任何内容。
  • 恢复不会覆盖原文件：它把副本写入恢复文件夹里的一个新文件夹，需要哪些再由你自己复制回去。
  • 它不提供文件内容下载；你到恢复文件夹里取恢复出的副本。
  • 它读取的是实时磁盘，而不是快照，所以每个恢复点都标有实时扫描。被其他程序锁定、或在读取过程中发生变化的文件可能被跳过，并显示为未能备份。

常见任务

  • 找回已删除的文件：在文件浏览中打开自上次备份以来已删除面板，打开该文件，点击恢复…。
  • 找回文件的旧版本：点击该文件，然后在要恢复的版本旁点击恢复…（见文件版本）。
  • 恢复整个文件夹：在时间机器中打开它，点击恢复此文件夹…。
  • 立即备份一个文件夹：在备份页点击立即备份。
  • 更改备份计划：在设置中点击编辑。

术语含义

登录与权限

不登录时

任何人都可以浏览。未登录的访问者（访客）可以使用文件浏览、时间机器、文件版本和备份页，但只限允许访客浏览的文件夹；其他文件夹对访客来说根本不存在。访客不能备份或恢复，不能打开审计、设置或状态，也看不到谁发起了任务、任务为何失败以及任务日志。

登录

  1. 点击右上角的登录，或者点击登录后可备份这样的按钮。
  2. 输入账号（工号、姓名或邮箱）和密码，然后点击登录。用工号最不容易产生歧义。
  3. 页面提供时，也可以点击使用 Windows 账号登录（SSO）：会弹出一个小窗口，完成后自动关闭（请允许本站弹出窗口，并使用公司电脑）。

登录后会回到你原来所在的页面。登录的有效期是有限的（设置页中服务卡片里的登录有效期）；用完后请点击右上角的退出登录。

权限级别

你能做什么是按监控文件夹分别决定的，每个级别都包含前面的级别。你无权使用的按钮不会显示。

级别允许做什么
浏览查看文件夹、其中的文件和历史，并从中恢复副本（恢复需要已登录的账号）。
备份包含“浏览”的全部权限，并可立即备份（包括完整重读）、校验恢复点、停止它的任务。
完全控制包含“备份”的全部权限，并可修改这个文件夹的设置以及谁能对它做什么。

权限可以授予访客（只能是“浏览”）、所有已登录的人或指定的人；你拥有适用于你的最高级别。你在某个文件夹上没有任何级别时，它对你不可见。备份页和设置页中，文件夹名称旁边的标签显示你的级别。

管理员对所有文件夹拥有完全控制权。只有管理员能添加监控文件夹、修改服务器上的文件夹、看到服务器本机磁盘上的文件夹，并使用立即检查来检查程序更新。

备份

备份页显示你可以浏览的每个监控文件夹的备份情况，让拥有相应级别的人启动备份，并列出最近的任务。如果没有可显示的文件夹，请登录或向管理员申请访问权限；管理员会看到管理监控文件夹。

文件夹卡片

  • 标题显示文件夹的名称，如果已停用则显示已停用，已登录时还显示你的级别。下面是显示文件夹；管理员还会看到服务器上。
  • 立即备份会读取文件夹，把新增和变化的文件复制到备份存储中，并记录一个新的恢复点；它绝不会修改该文件夹。完整重读做同样的事，但会重新读取每个文件，而不是仅依据大小和修改时间判断；它更慢，并且会把丢失的内容重新写入。两个按钮都需要“备份”级别，且文件夹处于启用状态；当该文件夹的备份正在排队或运行时，它们会变灰。如果访客登录后就能使用它们，则会看到登录后可备份。

恢复点

每张卡片中的表格列出该文件夹最近的 12 次备份尝试：

  • # 是编号；类型：文件夹的第一个恢复点为全量，之后的为增量（每个都显示整个文件夹）；采集时间是它的创建时间；文件数和大小是文件夹当时的内容量。
  • 状态：已提交表示已完成且可用；构建中表示仍在创建；失败和已中止表示没有完成，不显示任何内容（已登录的账号可以把鼠标指向“失败”查看原因）。
  • 变化：+3 ~2 -1 表示相对于上一个恢复点新增、修改和删除的文件数。未能备份统计备份无法读取的项目（大于 0 时显示为 2）。完整性显示完整性标签，适用时还有不完整。
  • 浏览会在时间机器中打开该恢复点。校验（需要“备份”级别）会重新读取每个已存储的对象并核对其校验值；标签会变为已完整校验或校验失败。在备份存储被复制或恢复之后，或者任何时候想确认某个恢复点完好无损，都可以使用它。

最近的任务与“恢复”卡片

最近的任务列出你可以浏览的文件夹最近的 25 个任务（编号、类型、监控文件夹、状态、创建时间、耗时、发起人）；点击编号可打开该任务。只有已登录的账号能看到任务的发起人，也只有他们能看到恢复任务和恢复卡片，该卡片说明恢复结果写在哪里（恢复结果写入某个网络文件夹之下），或者说明恢复功能已禁用。

任务

TimeVault 在后台做的每件事都是一个带编号的任务：备份、校验、恢复或版本清理。任务在等待轮到自己时是排队中（同一个文件夹的任务依次进行），然后是运行中，最后以成功、失败或已取消结束。可以在备份页或发起它的页面中打开任务。

  • 取消任务会停止排队中或运行中的任务。对该文件夹拥有“备份”级别的人，以及发起恢复的人，可以使用它。
  • 各项信息：监控文件夹、恢复点、发起人（仅已登录的账号可见；自动备份的发起人是 scheduler）、创建时间、耗时和阶段，阶段说明任务现在在做什么（例如“扫描并复制”“校验中”“恢复中”）。
  • 进度条和计数器显示已完成的工作量，页面每隔一两秒会自动刷新。
  • 错误说明任务失败的原因；访客看到的是任务失败。登录后可查看原因和日志。卡片日志仅对已登录的账号显示。
  • 恢复任务的页面（仅已登录的账号可见）还有恢复详情和一个项目表格，列有名称、操作、结果（成功、已跳过或失败）、大小和说明。标签页全部和仅失败项用来筛选，加载更多会再显示 200 项。每个失败的项目都会列出；非常大的恢复中，其他项目的列表在 20,000 项之后停止。

注意：只要有任何项目未能恢复，恢复任务就会以“失败”结束，即使其他内容都已复制。这也包括你用部分恢复选项排除在外的受阻项目。请打开仅失败项查看是哪些项目以及原因。

注意：没有发现变化的自动备份不会留下任务，所以你看到正在运行的任务，结束时可能已经不存在了。

自动备份与保留的版本

自动备份

  • 文件夹可以每隔 N 分钟（1 到 43200）自动备份一次；由拥有“完全控制”的人在设置中设定。间隔从上一次备份结束时开始计算。备份页和设置页会显示计划和下次备份的时间（或即将开始）；仅手动表示没有计划。同时到期的文件夹会被错开，所以备份可能比显示的时间稍晚开始。
  • 没有发现变化的自动备份不会记录任何内容：没有恢复点、没有任务、没有审计记录。上次运行仍会更新，而最新恢复点保持不变。立即备份则总会记录一个恢复点。
  • 已停用的文件夹不会被备份。设置计划或重新启用文件夹时，如果上次运行早于间隔，会立即开始一次备份。

每个文件保留的版本数

  • 每个文件夹可以限制每个文件保留多少个版本（1 到 10000；0 表示全部保留）。设置页把保留的版本显示为每个文件的全部版本或每个文件最新的 N 个。
  • 每次备份之后，它改动过的文件超出上限的版本会被永久删除，没有任何东西再使用的存储空间会被释放（空闲空间的变化可能要过一阵子才看得到）。失去版本的恢复点会被标记为不完整：它不再完整显示每个文件当时的样子，所以从它恢复可能不完整。
  • 对已有历史的文件夹设置上限或调低上限，会为整个文件夹排入一个版本清理任务。表单会先显示将删除多少个文件的多少个版本，并要求你勾选我知道这些版本会被永久删除。清理运行期间，该文件夹的恢复和校验会被拒绝，上限也不能更改。

警告：被删除的版本无法找回。没有上限时，对一直在变化的文件夹使用很短的间隔，会让备份存储无限增长。

状态

服务状态页（仅已登录的账号可见；通过页脚中的状态，或设置页服务卡片中的状态打开）会写明检查时间，并列出每个组件及其状态和详情。状态有正常、降级（仍在工作，但有问题）、未启用（尚未设置）和故障。

  • 数据库：正常；没有响应时为故障。
  • 备份仓库（备份存储）：写入测试和剩余空间。剩余不足 5% 时为降级，无法写入时为故障。

  • 用户账号（Redis）：没有响应时为降级；浏览和本地管理员仍可使用，但其他账号无法登录。没有配置时为未启用：只有本地管理员可以登录。
  • 恢复：正常；没有恢复文件夹时为未启用。任务队列：在你可以浏览的文件夹中，有多少任务正在运行和排队。
  • VSS 快照始终为未启用：TimeVault 读取的是实时磁盘。

常见问题

我看不到某个监控文件夹（“未找到该页面、文件夹或恢复点，或者你没有权限查看它。”）

文件夹只对被授权的人可见。如果还没有登录，请先登录；否则请联系管理员，或对该文件夹拥有“完全控制”的人，给你授权（设置、编辑、谁能做什么）。

“你没有权限执行此操作。”

你能看到该文件夹，但你的级别不够：备份、校验或停止任务需要“备份”级别，修改设置需要“完全控制”，而添加文件夹只有管理员才能做。这次尝试会作为访问被拒绝记入审计日志。

恢复按钮不见了或被禁用

你没有登录（登录后可恢复文件）；或者没有设置恢复文件夹（由于未配置恢复目录，恢复功能已禁用。），需要管理员处理；或者你没有勾选任何项目（恢复所选项…保持禁用）；或者该恢复点不可恢复，请选择另一个。

登录失败

账号或密码错误。请检查输入的内容；用工号最稳妥。失败次数过多，请等待几分钟后再试。请等待大约十分钟，即使最后一次的密码是对的也一样。无法连接用户账号服务。请稍后再试；浏览仍然可用。

使用 Windows 账号登录（SSO）不成功

如果浏览器拦截了登录窗口，请允许本站弹出窗口后重试。如果 Windows 无法识别你的身份，或者你的 Windows 账号在这里没有可用的账号，请在公司电脑上打开 TimeVault，或使用密码登录。其他情况请在同一台电脑的同一个浏览器中重试。

搜索提示不可用

搜索索引已关闭、还在建立中（服务启动后，较大的卷需要一段时间），或者无法读取该卷。其他功能都不受影响；请稍后再试，如果持续出现，请告知管理员：状态页会说明原因。

任务页面显示“未找到”，或者任务不见了

没有发现变化的自动备份不会留下任务。你无权浏览的文件夹的任务，对你来说同样是“未找到”。

没有“立即备份”，或者文件夹显示“已停用”

已停用的文件夹不能被备份，但它的历史仍可浏览。管理员或拥有“完全控制”的人可以在设置中重新启用它（备份此文件夹）。你还需要“备份”级别。

“表单已过期或无效，请刷新页面后重试。”

页面或你的登录太旧了。请刷新页面（F5），如有提示请重新登录，然后重复刚才的操作。

“预览已过期……”“该监控文件夹正在备份”或“该监控文件夹的旧版本正在删除”

恢复预览在 15 分钟后或发生变化（例如目标文件夹里的文件变了）时会过期：请查看新的预览，再次点击开始恢复。同一个文件夹的任务依次进行，所以对另外两条提示，请等正在运行的任务结束后再试。

文件显示“未能备份”，或一直是“新增”

未能备份：备份无法读取该文件（例如被其他程序锁定，或读取时发生了变化）。把鼠标指向该标签可看到原因，请稍后再运行一次备份；这样的文件无法从该恢复点恢复。新增在下一次备份成功后会变成已保护；如果它一直是新增，请查看备份页上的排除项，因为匹配排除规则的文件永远不会被备份。

“当前无法读取该文件夹，但时间机器中的历史记录仍可使用。”或“服务器发生内部错误。”

前一条表示目前无法在服务器上访问该监控文件夹；历史记录和恢复仍可使用。对于后一条，请记下页面上的参考编号。两种情况如果持续出现，都请告知管理员。
